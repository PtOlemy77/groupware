**적용 시 필요한 설정**

[README](../README.md)와 [.env.example](../.env.example)에 실행·관리자 복구·백업 절차가 있다. 기존 공통 비밀번호 계정은 자동으로 로그인 가능 상태로 유지하지 않는다. 지정 관리자 복구 후 직원 계정을 재설정해야 한다. 기존 데이터의 중복 이메일·잘못된 날짜·모호한 동명이인 등은 자동 삭제·임의 매핑하지 않으며, 마이그레이션 오류를 확인하고 실제 값을 정리해야 한다.

계약 시트는 버전을 검증하는 JSON 스냅샷으로 유지한다. 모든 시트를 별도 테이블로 분해하는 재설계 대신 관계 ID·스키마 검증·서버 계산·원자적 저장·승인 이력을 보강했다. 기존 승인 문서를 자동으로 새 금액으로 덮지 않는다.

테스트는 격리 DB·PostgreSQL 엔진과 로컬 브라우저 기준이다. 운영 네트워크의 TLS·DB 권한·백업 보존 정책과 실제 회사 데이터의 정합성은 배포 환경에 맞게 적용·확인해야 한다.
