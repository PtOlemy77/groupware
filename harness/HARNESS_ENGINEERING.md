# 2. 코딩 원칙

- 모든 소스는 인간이 이해하기 쉬운 형태로 코딩한다.
- warning경고는 무시하지 않고 해결한다. 단, 해결을 위해 처리해야할 일이 많고 성능이 떨어지는 행위라면 그대로 둔다.
- 사용하지 않는 import는 제거헌다.
