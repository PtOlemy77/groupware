## 1. 제품 개요 (Product Overview)

### 1.1 배경 및 목적
(주)스패셜티는 공간정보 및 IT 솔루션 전문 기업으로서, 프로젝트 중심의 업무 구조와 임직원 인력 풀, 장비 자산, 주간/월간 실적 보고, 인사 평가를 유기적으로 연결하는 엔터프라이즈 통합 그룹웨어를 운영한다.

### 1.2 핵심 설계 철학 (Harness Engineering Invariants)
본 시스템은 다중 AI 에이전트와 엔지니어가 지속 가능하게 협업할 수 있도록 아래 4대 절대 불변식을 요구사항 전반에 강제한다:
1. **데이터 보존 (Data Preservation)**: 서버 재기동 시 기존 DB 레코드를 임의 덮어쓰거나 초기화하지 않음 (`DataInitializer`).
2. **코드 기반 구분값 관리 (Code-based Discrimination)**: 권한, 직급, 부서, 상태 등의 모든 구분값은 한글 문자열이 아닌 시스템 코드 상수로 관리/비교함.
3. **표준 전역 모달 UI (Global Modal Only)**: 브라우저 기본 `alert`/`confirm` 사용을 전면 배제하고 전역 모달 컨텍스트를 사용함.
4. **엄격한 PK/FK 정규화 관계 유지**: 텍스트 매칭 조인을 배제하고 기본키/외래키 기반의 무결성을 유지함.

## 2. 사용자 역할 및 권한 체계 (Role & Permissions)

모든 권한은 `RoleCode` 상수로 엄격히 식별되며 프론트엔드/백엔드 이중 검증을 거친다.

| 역할 코드 | 명칭 | 대상자 예시 | 주요 권한 범위 |
| :--- | :--- | :--- | :--- |
| **`ROLE_ADMIN`** | 시스템 관리자 | 우광일 대표이사 / 전산관리자 | 전 기능 접근, 임직원 권한 변경, 기준정보(공통코드) 관리, 전사 감사 |
| **`ROLE_EXEC`** | 임원진 | C-Level, 사업본부장 | 전사 통계 조회, 기준정보 열람/관리, 결재 최종 승인, 인사평가 총괄 |
| **`ROLE_PM`** | 프로젝트 관리자 | PM, 프로젝트 PL | 프로젝트 투입 인력 배정, 주간/월간 업무 보고 작성/승인, 팀원 실적 관리 |
| **`ROLE_STAFF`** | 일반 직원 | 개발자, 디자이너, 연구원 | 본인 프로필 조회, 배정된 프로젝트 열람, 본인 장비 확인, 자기 인사평가 작성 |

## 3. 기능별 세부 요구사항 (Functional Requirements)

### 3.1 사용자 인증 및 세션 관리 (Auth & Security)

| ID | 요구사항 명 | 상세 내용 | 필수 규칙 |
| :--- | :--- | :--- | :--- |
| **AUTH-01** | 사용자 로그인 | 사내 이메일/사번과 비밀번호를 이용한 세션 기반 인증 | BCrypt 단방향 암호화 |
| **AUTH-02** | 최초 로그인 비밀번호 강제 변경 | `password_change_required=true`인 계정은 접속 즉시 비밀번호 변경 모달 표시, 변경 완료 전까지 타 화면 접근 차단 | 기본 초기 비밀번호 변경 강제 |
| **AUTH-03** | 무활동 세션 타임아웃 | 30분간 사용자 마우스/키보드 입력이 없을 시 자동 로그아웃 처리 | `InteractionGuard` 동작 |
| **AUTH-04** | 로그아웃 | 세션 즉시 파기 및 상태 초기화 후 로그인 화면으로 리다이렉트 | 클라이언트 상태 초기화 |

## 4. 비기능적 요구사항 (Non-Functional Requirements)

1. **프론트엔드 성능 및 번들링**:
   - React 19 + Vite 초고속 HMR 지원.
   - 빌드 시간 1초 미만, 초기 페이지 로드 500ms 이내.
2. **백엔드 안정성 및 트랜잭션**:
   - Spring Boot 3.4.5, Java 25 환경.
   - 비즈니스 서비스 `@Transactional` 처리 및 동시성 제어.
3. **데이터베이스 무결성**:
   - PostgreSQL 16 기준 엄격한 Foreign Key 제약 조건.
   - Flyway를 통한 체계적인 DB 마이그레이션 관리.
4. **접근성 및 반응형 지원**:
   - 데스크탑(1920x1080), 태블릿, 모바일 해상도 대응 레이아웃.
   - Tailwind CSS v4 기반의 일관된 디자인 시스템.

## 5. 하네스 검증 게이트 (Verification Gates)

모든 개발 및 AI 에이전트 작업은 다음 3대 명령을 100% 통과해야만 배포/커밋이 승인된다:

```bash
# 1. 프론트엔드 타입 안전성 검증
npx tsc --noEmit

# 2. 백엔드 컴파일 및 빌드 검증
JAVA_HOME=/Library/Java/JavaVirtualMachines/temurin-25.jdk/Contents/Home ./backend/mvnw -f backend/pom.xml compile -DskipTests

# 3. 프론트엔드 프로덕션 빌드 검증
npm run build
```
