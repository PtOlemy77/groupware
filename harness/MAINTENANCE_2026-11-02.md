# 하네스 정비 기록 — 2026-11-02

이 문서는 이번 정비의 기록이다. 현재 작업 규칙은 [AGENTS.md](../AGENTS.md), 검증 정의는 [하네스 기준](HARNESS_ENGINEERING.md)과 [실행 스크립트](../scripts/verify.mjs)를 따른다.

## 변경

- AGENTS·README·PRD·디자인·하네스의 역할을 분리하고 Vite/Java 지원 환경·실행 경로를 통일했다. 과거 검토 문서에는 시점 구분을 표시했다.
- PRD에서 구현·부분 구현·계획을 구분하고 공개 포털·공지·개인정보 초안 및 미검증 운영 항목을 추가했다. 자기평가·성능 수치를 구현 완료처럼 설명하지 않도록 정정했다.
- `verify`와 `verify:full`을 단일 진입점으로 추가하고 CI도 전체 파이프라인을 사용하도록 변경했다. 개인 JDK 경로·Next.js 실행 의존을 제거했다.
- 네이티브 알림/확인 참조의 AST 검사, 민감 추출본 추적 차단, 공유 문서의 비밀번호 해시·파일 링크 검사를 추가했다. 검사기의 거절·허용 사례도 테스트한다.
- 기존 직원이 있으면 초기화기가 아무 값도 바꾸지 않도록 수정했다. 빈 DB 최초 관리자는 비밀번호 변경을 요구한다. 기존 계정 복구는 기동 환경변수로 가능하다고 안내하지 않는다.
- 그룹웨어·공지의 버전 누락 수정은 400, 오래된 버전은 409로 거절한다. 누락 요청이 데이터에 영향을 주지 않는 회귀 검사를 추가했다.
- 네이티브 함수 fallback/전역 치환을 제거했다. 미저장 이탈을 비동기 확인으로 전환하고 아이콘 닫기 버튼도 보호한다. 모달의 취소·Escape·Tab·포커스 복귀를 브라우저로 검사한다.
- 게이트가 발견한 매출 회귀(사업 기간 밖 연도, 명시한 수기 배분의 누락 연도)를 수정했다. 보고서의 예제 실적·피드백·제출 시각·조회 시 자동 저장을 제거하고 KST 기준 기간·ID 기반 매핑·공통 API/버전 전달을 적용했다.
- 포털 복귀 링크가 사이드바 뒤에 가려지는 문제를 수정했다.
- 데이터가 들어 있던 DB 명세는 데이터 없는 관계·제약 안내로 교체했다. 원본 문서의 로컬 사본, 기존 CSV와 전체 덤프는 보존하고 Git 추적에서 제외했다. 최신 DDL 기준은 Flyway다.

## 검증 결과

Java 25와 로컬 Chrome을 사용하여 저장소 루트에서 `npm run verify:full`을 실행했다. Java 21 CI 설정은 유지하되 원격 CI 결과를 로컬 결과로 대체하지 않는다.

## 남은 범위

- 과거 Git 커밋에 들어간 추출 자료는 이번 정비로 삭제되지 않는다. 과거 공유 범위·자격정보 대응·이력 정리는 별도 작업이며 강제 푸시나 이력 재작성은 수행하지 않았다.
- 모든 기존 업무 분기의 코드 기반 판정 전환, 운영 TLS·프록시·권한·로그 보관·백업 복원, 개인정보 담당자/호스팅/보유기간 확정은 이 검증으로 완료됐다고 주장하지 않는다. PRD의 부분 구현·운영 미검증 항목을 따른다.
- 코드·문서 정비와 로컬 검증 결과이며 운영 DB 변경·운영 서버 재기동·배포는 수행하지 않았다.
